# Review of 20 Albanian-language materials (November 2026)

Purpose: assess suitability for ALBA AI 3.1, an experimental assistant for drafting and editing institutional/legal Albanian. Titles, years and authors reflect the supplied PDFs. All recommendations are editorial screening, **not** expert validation of linguistic norms. The public GitHub library contains only small, original paraphrases; no uploaded PDFs or copied dictionaries.

## Included as carefully qualified editorial guidance (5)

| File | Publication | Decision and limitations |
|---|---|---|
| `struktura_gramatikore_e_fjaleve_me_vizelidhese_ne_fgjssh.pdf` | A. Spahiu (2008), grammatical structure of hyphenated words in FGJSSH 1980 | R26: select established hyphenated compounds, not a rule to hyphenate all combinations; verify normative labels separately |
| `kalket_gjuhesore_e_zvetenojne_natyren_e_gjuhes_sone.pdf` | A. Spahiu (2002), syntactic calques | R27: avoid demonstrable unnatural calques, use source-backed examples in context; author's broader value judgments are not adopted |
| `emra_permbledhes.pdf` | A. Spahiu (2009), collective nouns in FGJSSH 1980 | R28: note singular collective nouns and verify agreement; historical vocabulary requires context |
| `samiislami_shqipfoles.pdf` | S. Islami (2010), Shqipfolës apo shqiptar? | R29: distinguish language use from nationality/ethnicity when material; do not adopt political claims |
| `fjala_shqipe.pdf` | S. Kelmendi (compiled 2000), alternatives to foreign words from Gjuha Jonë | R30: offer candidate equivalents only, with legal/technical semantic guardrails; do not auto-load wordlist or force purist substitutions |

## Not suitable as automatic drafting/terminology guidance (8)

| File | Reason |
|---|---|
| `frazeologjia_ne_fgjssh.pdf` | 224 pages dominated by idioms; many figurative/colloquial expressions inappropriate in legal/institutional drafting |
| `ndikimi_i_ideologjise_ne_varietete.pdf` | Sociolinguistic analysis of spoken standard and ideology, not written administrative norms |
| `standartizimi.pdf` | Despite filename, a 2013 paper on *spoken* Albanian after standardisation, not orthography rules |
| `pastertia_e_gjuhes_shqipe.pdf` | Normative/purist opinion; some proposed replacements confuse specialist meanings |
| `samigjuhaletrare.pdf` | Polemical history of standardisation, not a practical standard-writing reference |
| `Liste_fjalesh_te_huaja_te_zberthyera_ne_gjuhen_shqipe.pdf` | Context-free pairs include non-equivalences, e.g. 'certifikatë' vs 'vërtetim' and 'aplikim' vs 'zbatim' |
| `a_mund_te_quhen_fjale_reja.pdf` | Author's opinion on borrowing terminology, not normative usage guidance |
| `lokucionet_foljore_ne_fjalorin_e_f_bardhit.pdf` | Valuable historical lexicography, not a modern institutional style source |

## Review safeguards

1. No uploaded PDF is mirrored or redistributed by ALBA.
2. Source metadata is linked to public publication URLs where checked; the publication website is not necessarily an official normative authority.
3. Active R26–R30 entries remain `editorial_draft` and require expert review before approval.
4. Do not use a wordlist as a thesaurus for automatic substitutions, especially for EU acquis, legal, financial and administrative terms.
5. This classification is for ALBA's use case only; it is not a judgement on the scholarly merit of individual papers.
